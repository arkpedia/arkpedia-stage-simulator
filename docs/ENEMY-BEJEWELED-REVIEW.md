# Bejeweled Slab defenders

Both original records use a shared damageAdaptation component. Physical and
Arts packets advance separate permanent counters. Thirty Physical instances
supply +2,000 DEF; thirty Arts instances supply +80 RES. Each instance contributes
one thirtieth of its channel's maximum. The native passive's additive taunt
modifier is applied alongside the record's existing taunt, and the common
handbook wording is covered by the ordinary taunt priority contract.

The shared accepted-damage receipt counts attack and non-attack instances,
including damage over time, shielded hits and accepted zero-damage packets.
Misses, invulnerability and absent/hidden recipients never reach it. True damage
and HP loss do not advance either channel. The current packet has already been
mitigated; later packets see the new defenses. This ordering and linear
saturation are explicit local mappings, not compiled-client ordering claims.
The source passives are nonsilenceable; control does not remove adaptation.
