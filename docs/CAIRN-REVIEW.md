# Cairn source and runtime review

Cairn remains held outside the public roster. The normal preview contains 386 frozen source forms and 842 skills. Source preparation, runtime behavior, artwork delivery and public gameplay verification are separate gates.

The frozen foundation `data/arkpedia-native-operators/char_4214_cairn.json` contains 245,569 bytes, SHA-256 `c3b66218299c5e18daea25e691e7777a3273329e96ae757f067434ba118e876a`. It uses original CN commit `a550f5e048bb94e7cdefc6eb97a4091f0c4c7add`, client `26-09-22-07-47-20_6c71fa`. Five native bundles retain 58 owner/skill components and eight transitive templates, with no referenced projectile/token graph or unresolved template. Independent reproduction on Node 22 and 24 preserves seven output files and rejects 28 altered-source or premature-approval claims per run.

Twenty-two source-selection and exact-clock checks pass on both Node versions. They cover both skills at all ten ranks, promotion/potential/trust, locked selections, original animation payloads and rejection of changed source bytes. These checks do not install combat behavior.

The selected runtime must preserve these source distinctions:

- Ordinary and S1 attacks target one enemy. Cairn blocks three; this does not make him attack three enemies at once. Original targeting is sampled at input, with one `OnAttack` marker at approximately 0.6 seconds and native maximum animation scale 1.
- S1 increases maximum HP for thirty seconds. Its native mode maps attacks and idle to `Skill_1_Loop` and `Skill_1_Idle`, with a short Begin and four native End transition pairs.
- S2 is an instant skill with a one-shot `Skill_2` animation. Nearby ground recipients are selected at its attack marker. The attached damage buff snapshots ATK on attachment; its Arts and neural-injury paths remain distinct. The elemental branch explicitly permits source-free output after source death.
- The S2 shield adds a fraction of current maximum HP, caps against the selected maximum-HP ratio and uses the native EXTEND lifetime policy. It is not a permanent HP increase or a decaying overheal barrier.
- The talent attaches to enemies blocked by Cairn, rejects invincible recipients at attachment and derives a one-second injury child from the parent. It uses current source ATK; ending the parent also ends the child.

Raw lifetime/trigger fields are retained, including S2 damage's `lifeTime=4`, `triggerCnt=4`, `triggerLifeType=2`, the selected `buff_duration=10`, and one-second first/recurring delays. These fields alone do not establish the compiled dispatcher or expiry-frame policy. The runtime must document and test that mapping explicitly before admission. Source skill text, numeric enums, native callback phase, source-removal attribution and shield extension must not silently become claims of executable Unity parity.

Modules, native particles/shaders/audio and game-frame/pixel parity remain unverified. Arkpedia app dev and production remain untouched.

The held resource adapter now supplies the selected maximum-HP modifier, capped finite shield, snapshotted paired skill DOT and current-ATK blocked talent. It requires an explicit resource contract and rejects modified source definitions. It does not install attacks, cast markers, a public kit or a roster entry. The resource test fixture deliberately has no attack/cast controller; method calls are diagnostic, not a playable skill claim.

Its explicit timer mapping follows the selected ten-second skill text with ten delayed one-second pulses including expiry. The raw native lifetime/counter fields above remain unchanged and are not presented as a recovered dispatcher. The native default DOT override maps to one shared recipient key with replacement and a fresh ATK snapshot; the shield EXTEND maps to the greater remaining lifetime. Current block membership is sampled once per tick, invincibility is checked on attachment, and a new block restarts the full one-second talent delay. Neural injury remains separate from dodged, cancelled or shielded Arts output. Non-derived recipient DOTs survive source retirement; the Arts path retains its source object while the elemental path becomes source-free when that deployment is absent. Shared-source modifier/credit behavior after reusing a unit object remains an explicit engine boundary.

Sixty-three Cairn source/clock/resource checks and the adjacent barrier, HP, damage, elemental and buff-removal checks pass on Node 22 and 24: 165 tests per version, zero failures. The held tests cover all twenty skill ranks, shield depletion/refresh/expiry/caps, captured/current ATK, ten DOT pulses, source retirement, block loss/reblock, initial invincibility, silence/control, rejected/reentrant attachments and unsupported input rejection.

The original artwork recipe verifies both existing model records, native pointer chains, decoded pixels, PMA and six unchanged files. It reproduces the receipt and rejects 33 altered art claims on both Node versions. Browser checks load all seventeen clips per viewport, compare exact durations, and record eighteen desktop/emulated-mobile captures with no browser/resource errors; desktop S2 and mobile S1 were visually inspected. Recipe-selected capture phases now cover Cairn's one-shot S2 without inventing absent Begin/Loop/End tracks. A separate held combat controller now binds the resources to source attacks and both skills. Forty-four combat checks cover the twenty skill ranks, natural/manual SP, input-time single targets, marker-time ground recipients, empty S2 releases, S1 Begin/End, original Front/Back clocks, animation speed, retained cooldowns, short control epochs, external finish, reentrant source removal and retirement cleanup. The complete Cairn/source/clock/resource/combat and adjacent regression set passes 209 tests per Node version (22 and 24), zero failures.

Its timing contract is explicit: S1's thirty-second account starts at activation, the HP mode starts after the unscaled Begin, and its native End transition holds its own duration. S2 holds SP throughout its one-shot clip, attaches to current ground bodies at the native marker, grants its independent shield at that same marker even without a recipient, then finishes at clip end without creating a normal attack receipt. Source selector and callback enum aliases, the ordinary cycle lower bound, S2 shield callback phase and original compiled FSM ordering remain mappings. Rejected S1 attachment keeps ordinary mode; accepted non-derived S2 children survive a later interruption or retreat.

The first combat test pass caught a missing event-payload join between the additive exact-clock receipt and original model data; the controller now uses both inputs. It also caught a native End visual that stayed displayed during a positive ordinary cooldown. End completion now restores idle without resetting that cooldown. Both repairs are included in the passing results above.

Cairn still has no public roster entry, loadout/card assets, original-wave completion or public mouse/touch gameplay review. Those gates, the full local suite and hosted matrix are pending. The normal preview remains unchanged.
