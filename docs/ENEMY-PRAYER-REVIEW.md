# Invitation to Prayer

Both Flippers of the Sankta variants now use a shared timed global stat-debuff
controller. Original records provide the 20-second initial delay, 40-second
cooldown, 15-second duration and −30 ASPD. The original Skill clip releases at
1 second and finishes at 65/30 seconds. Slow Down scales the cast clock; silence
and disabling control interrupt unreleased casts. Cooldown starts when the cast
begins. Finishing or interrupting preserves the enemy's nonattacking profile.

The native selector captures eligible ground characters when casting begins,
including concealed recipients and explicitly targetable devices. An empty
battlefield still consumes the cast. Later deployments are not added at release;
dead or removed recipients are skipped. Different casters extend the same buff
without stacking its modifier. The released debuff survives source death.

Admission checks the bounded pair's original wrapper, selector, buff modifier,
empty ordinary attacks, animator binding and extracted animation events. Public
assembly enum declarations corroborate beginning-selection and extend semantics;
links and blob identities are retained in `data/arkpedia-prayer-review.json`.
The shared timed-cast controller's existing Dorothy behavior passes regression.

Six focused and 192 combined tests pass. Both original bodies decode all ten
clips on desktop and touch, and the desktop gallery was inspected. The shared
asset store contains 3,754 complete models; 474 additional enemy artwork records
are available. This is body/clip validation, not native particles or pixel parity.
The available stage graphs remain 905, all passing the ten-second runtime smoke;
other mechanics still block affected maps. Enemy support rises to 678 of 2,163.
