# Night Archers

Both Night Archer variants now use one on-demand projectile-mode component. Their retained native buff program selects Arts mode on an invisible owner tile and physical mode otherwise, at attack boundaries. Silence disables the source-silenceable parent and resets future casts to physical. A cast already captured by the native non-interruptible action retains its packet. Released projectiles survive source death; pending casts do not.

The shared compiler now accepts bounded, explicit mode checks/switches and the native owner-tile NIGHT predicate. It rejects dynamic mode indices, FSM restarts and implicit default restoration. Programs validate their required services before effects, per event; disabling a removed actor does not query its former tile. Mode state belongs to each actor, while immutable program data is shared. The environment provider boundary is also shared with Gloompincers.

Admission checks both source modes, selectors, packets, passive scope, animation clocks and straight projectile transport. The ordinary variant alone has the native killed-result receipt. The separate visual marker holder is checked to contain no gameplay effects. Original particle effects and native frame ordering are not claimed.
