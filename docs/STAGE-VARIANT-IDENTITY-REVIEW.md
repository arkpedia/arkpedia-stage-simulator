# Variant identities and difficulty masks

Six-star variants now require a verified mapping to their shared parent level
and activate `ALL` plus `SIX_STAR` rules. Four-star and easy rules remain inactive.
Unknown active modifiers still block admission; this does not mark Chapter 15's
environment controller or its dependent enemies as implemented.

Integrated Strategies variations are independent levels linked by the viewer
for navigation. Their source path must match their own level identity, and they
use normal difficulty rules. A parent level cannot stand in for an alternate's
map, waves or rules. Other special variant kinds retain their existing blockers.

Forty-seven adverse-environment bindings that still referenced normal parent
levels were refreshed from the pinned stage table and original Git blobs. New
immutable evidence is published before each binding is atomically replaced;
the old evidence remains available. All refreshes completed. This corrected
source selection exposes the actual remaining mechanics rather than admitting
a stage with its parent's behavior. No new stages were admitted by these
identity changes alone.

Tests cover difficulty isolation, identity/path mismatches, empty six-star
evidence, independent IS variations and unknown active rules. Current blockers
are generated in `docs/REMAINING.md` and the content inventory.

All 184 stale Integrated Strategies variation bindings have now also been
refreshed to their own immutable original level blobs. Of these, 125 pass the
rule compiler; the rest expose specific unsupported selectors/controllers.
Other enemy, device, wave and mode gates still apply, so this repair alone
admits no additional stages. The atomic refresh results are retained in
`data/arkpedia-is-variant-refresh-review.json`.
