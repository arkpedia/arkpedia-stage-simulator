## Selected aura and grounded healing

The accepted aura parent owns its conditional Sanctuary and block children. Source FLY maps to original FLY motion or the existing ally liftoff flag; grounded, isolated, hidden and otherwise invalid recipients receive no flying-only attributes. The block family admits one bonus across producers, while Sanctuary retains ordinary strongest-source Physical/Arts semantics and does not reduce True or elemental HP damage. Range exit, landing, parent removal, source/recipient replacement and battle end clear only owned resources. Source-hidden state suspends the aura and can resume on the same living deployment. Native notifications/family arbitration map explicitly to world-tick updates; source silence/control does not disable the unsilenceable passive.

Grounded healing retains one injured friendly input life, the original Attack marker, one receipt and independent speed-eleven/ten-second transport. Acquisition maps to lowest HP ratio with explicit tie ordering. Captured full-health or newly untargetable inputs are not replaced by a different recipient. The shared healing pipeline still enforces heal-free/incoming multipliers and recipient-life guards. Matching source life supplies live ATK, attack scale and output healing; a retired/replaced source uses the launch snapshot. Transient control cancels an unfired phase with positive cooldown preserved. A .6 marker encoded as float32 `.6000000238418579` uses a small source-precision tolerance rather than slipping another 30-Hz simulation frame. Full-precision receipt values remain unchanged.

Source replacement tests exposed a real old-projectile bug: snapshotting only ATK still let the new source life donate or zero its output-healing multiplier. Both zero and nine multiplier cases failed before the fix. The same explicit fallback now protects Ukusik's independent chain and periodic attachments. Invalid/zero supplied multipliers create no healing. This is an explicit local source-invalid fallback, not recovered compiled-client attribute dispatch.
