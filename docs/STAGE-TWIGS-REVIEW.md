# Twigs That Crave

The reusable device controller now loads the original instance's route binding
and pollution operands. Visible instances initialize once; hidden instances use
the existing wave activation path. The native 1.1-radius colliders are distinct
from the displayed cross-shaped range. Runtime circle tests include the shared
ally body radius. Pollution uses the shared nonstacking recipient clock and
stops when its producer is removed.

HP strictly below 50% permanently enables the elemental attack. It captures
eligible recipients every four seconds, releases 250 Necrosis at the original
Attack_A event at 10/30 seconds, and completes the one-second clip. The device
retains native stun, silence, freeze, sleep and levitation immunity. It uses no
operator slot and cannot retreat. An empty attack still consumes the interval.

Death releases only the original selected branch action. A device-owned .1-second
progress check keeps victory pending long enough to release its child when the
counted enemies are resolved. The managed child is uncounted and holds victory.
The compiled branch scheduler owns its route and lifetime independently of the
destroyed device. Occupied-tile activation cannot create an orphan controller.

This work also corrects the existing Rot Eater adapter. Ordinary entry-point
spawns keep full stats. Managed branch spawns freeze the resolved counted-enemy
fraction at birth, clamped to 20–80% before completion and 100% at completion.
HP, ATK and DEF use ordinary persistent modifiers. The prior implementation
incorrectly increased stats with a per-player kill count. Its polling pollution
zones are replaced with one removable moving field.

Level progress maps to `(killed + leakedCount) / total`, with an empty counted
schedule treated as complete. This interpretation includes escapes as resolved
enemies. Serialized native action names and public mechanic references support
the mapping; compiled game methods and exact Unity ordering are not verified.
The controller's initial four-second attack wait, fixed-tick threshold sampling,
captured-target lifetime and body-radius overlap are explicit local mappings.

The source importer still rejects the placement with duplicate conflicting
`Polluted_damage_low` values. Its ambiguous map remains blocked. Other maps can
remain blocked by unrelated enemies or modes. No stage-specific combat code was
added. Source contracts, runtime definitions, instance validation, branch programs
and the shared body manifest each retain one reusable record.

The earlier preparation checkpoint is retained in STAGE-TWIGS-PREPARATION.md.
The first integration suite passed 231 tests. Nine further focused checks cover
native mutations and controlled full-stage runs of 11-7 and 11-8, including
uncounted full-strength children holding final victory. Original device artwork
passes four desktop and mobile clip checks; the desktop gallery was inspected.
Native pollution particles/audio and original-client frame parity remain outside
this review. Compilation now admits 911 of 3,892 stages.
